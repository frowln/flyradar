# SkyAtlas — проверка на устройстве

*Для сборки 1.0. Всё, что можно проверить без телефона, уже покрыто тестами и
скриншотами (`npx vitest run`, `scripts/preview/shoot.mjs`). Здесь то, что
проверяется только на реальном iPhone — и лучше всего в реальном полёте.*

Отмечайте: ✅ работает · ❌ не работает (что именно, скриншот) · — не проверялось.

Сборка: `npm install` в корне → `cd apps/mobile` → `npx expo run:ios --device`
(для проверки как в сторе — `--configuration Release`).

---

## 1. Первый запуск

| # | Действие | Ожидается | |
|---|---|---|---|
| 1.1 | Установить и открыть | Сплэш: окно иллюминатора на тёмном фоне, затем онбординг. Белой вспышки нет | |
| 1.2 | Иконка на рабочем столе | Иллюминатор с оранжевым маршрутом, без белых углов | |

| 1.5 | Закрыть и открыть приложение | Онбординг больше не показывается | |

## 2. Демо-полёт (4 минуты)

| # | Действие | Ожидается | |

## 3. Добавление настоящего рейса (по Wi-Fi)

| # | Действие | Ожидается | |
|---|---|---|---|
| 3.1 | «Добавить рейс», набрать «моск», «SVO», «Шереметьево» | Аэропорт находится любым способом, на русском | |
| 3.2 | Выбрать дату, время, «Подготовить» | Прогресс: маршрут → места → истории → фото → карта; 10–60 с | |
| 3.3 | Сразу после подготовки | Системный запрос на уведомления (если ещё не давали) | |

| 3.5 | Карточка любого места | Текст из Википедии на русском (или английском с пометкой), фото с автором и лицензией | |
| 3.6 | Включить авиарежим, открыть карточки | Текст и фото на месте | |
| 3.7 | Отсканировать посадочный (камера) | Заполняются аэропорты, дата, номер рейса, место; время вылета — вручную | |
| 3.8 | Импорт .pkpass из «Файлов» | То же | |
| 3.9 | Рейс, который нельзя построить (один и тот же аэропорт) | Понятное сообщение, приложение не падает | |

## 4. Напоминания на земле

Добавьте рейс с вылетом через 1–2 дня **без указания места**.

| # | Действие | Ожидается | |
|---|---|---|---|
| 4.1 | За сутки до вылета | Уведомление «Регистрация: просите окно слева/справа» с названиями мест | |
| 4.2 | Через 15 мин после времени вылета | «Уже в воздухе? SVO — AYT» | |
| 4.3 | Долгое нажатие на это уведомление → «Взлетели» | Приложение открывается сразу на экране полёта, полёт идёт | |
| 4.4 | Простое нажатие | Открывается «Борт» с вопросом «Когда взлетели?» | |
| 4.5 | Удалить рейс | Напоминания по нему больше не приходят | |
| 4.6 | Настройки → «Уведомления в полёте» → «выкл» | Напоминания не приходят | |

## 6. Настройки и прочее

| # | Действие | Ожидается | |
|---|---|---|---|
| 6.1 | Сменить язык по кругу | Все экраны на выбранном языке, ничего не обрезано; японский — японским шрифтом | |
