# Демо для заказчика

*Октябрь 2026. Как открыть демо, что показать на записи и чем веб-демо отличается от приложения на iPhone.*

## Где открыть

**Ссылка:** https://claude.ai/artifact/35t3c9YiACqTLudfor2c3W

По умолчанию страница видна только владельцу. Чтобы показать её заказчику по ссылке, откройте доступ кнопкой «Поделиться» на странице.

Демо — то же приложение, что и на iPhone, собранное для браузера. Работает без сервера и без интернета после загрузки страницы: маршрут, места, истории, рельеф и спутниковые снимки встроены.

**Как записывать:**
- **На телефоне** — откройте ссылку в Safari и включите запись экрана из Пункта управления.
- **На компьютере** — приложение показывается в рамке размером с iPhone, посередине экрана. Запись экрана: ⇧⌘5 на Mac, Win+Alt+R в Windows.

Язык интерфейса берётся из браузера: русский браузер — русский интерфейс. Доступны ещё английский, немецкий, французский и испанский. Японский в опубликованной версии выключен, чтобы уложиться в лимит размера.

## Перед записью

Пролетите заранее два-три демо-полёта по разным маршрутам: «Борт» → «Или выберите, куда лететь». На каждый уходит 4–6 минут, можно не смотреть. Тогда на записи «Атлас» будет с картой полётов, штампами и уровнем, «Мой год в небе» — с цифрами, а в рейтинге появится ваша строка. Всё хранится в браузере: на другом устройстве или в режиме инкогнито паспорт будет пустым.

## Сценарий записи (6–8 минут)

Демо-полёт идёт в 20 раз быстрее реального: два часа до Сочи — за шесть минут. Говорить можно поверх. Ниже — что нажимать и что сказать.

### 1. Первый экран (20 с)

Три карточки онбординга:
- «Что за окном»;
- «С какой стороны и когда»;
- «Паспорт неба».

> «Приложение рассказывает, над чем вы летите, — и работает в авиарежиме».

Дальше два пути:
- **«Попробовать демо-полёт»** — маршрут выбирается сам по времени суток. Для русского интерфейса днём это Москва → Сочи; если в Москве ночь — туда, где сейчас день: Альпы, Гималаи, Фудзи, Анды.
- **«Пропустить»** → экран «Борт» → внизу «Или выберите, куда лететь» → **«Москва → Сочи · над Кавказом»**. Так маршрут выбираете вы. Если там сейчас ночь, на кнопке написано «там сейчас ночь»: карта и вид из окна будут ночными, с огнями городов.

### 2. Экран полёта — карта (60 с)

- Цветная карта с рельефом: горы с тенями, реки, озёра, города, границы — подписи по-русски.
- **Силуэт самолёта** повёрнут по курсу. Оранжевая линия — пройденное, пунктир — впереди.
- **Полупрозрачные секторы** по бокам — что видно из левого и правого окна. Ваш сектор янтарный.
- Карта следует за самолётом. Приближайте двумя пальцами (в браузере — колесом мыши): самолёт остаётся в центре.
- Сдвиньте карту пальцем, чтобы посмотреть в сторону. Появится кнопка **«◎ к самолёту»**: карта вернётся к самолёту и снова поедет за ним.
- **«Во весь экран»** — карта на весь экран.
- **«Ночная»** — тёмная карта для салона, с огнями городов.
- Нажмите на точку места на карте → откроется карточка.

> «Можно прилипнуть к карте и следить за своим самолётом, как в Flightradar, только с рассказом о том, что внизу».

### 3. Ползунок «проведите по линии» (30 с)

- Потяните кружок вправо: самолёт «перелетает» вперёд. Карта, «сейчас за окном» и вид из окна показывают тот момент: «через 0:44».
- Засечки на линии — главные места: сверху — слева по борту, снизу — справа.
- **«К самолёту»** — вернуться в настоящее.

> «Так же удобно посмотреть рейс заранее, дома: где будет Эльбрус и какое место у окна просить».

### 4. Показатели (10 с)

- Осталось, пройдено, высота.
- Скорость, курс, температура за бортом, местное время внизу.
- При пересечении границы сверху появляется плашка: флаг, «Вы в небе: Казахстан», местное время, «штамп в паспорт». Смена часового пояса тоже отмечается.

### 5. «Вид из окна» (40 с)

Самая сильная часть — её нет ни у кого из конкурентов.

- Переключатель **«левое / правое»**.
- Нарисованная панорама с высоты полёта до горизонта: хребты слоями, снег на вершинах, подписи вершин и городов с расстоянием («Гора Эльбрус · 5 642 м · 180 км»).
- Нажатие на подпись открывает карточку места.

> «Под облаками или ночью вы всё равно знаете, что там: панорама считается по данным высот, а не снимается камерой».

### 6. Карточка места (40 с)

Откройте место из «Дальше» или с карты: Кавказ, Эльбрус, Дон, Воронеж.

- **Первое фото — снимок со спутника Sentinel-2:** «вид со спутника · кадр 24 км». Так место выглядит сверху — как из иллюминатора.
- Затем рассказ, «что искать в окне», факты, история под крылом.
- **«Вижу!»** — золотой штамп.
- Аудиогид читает вслух. В браузере голос зависит от системы.

### 7. Игры в полёте (20 с)

- «Угадайте, что внизу» — карточка с вариантами появляется сама, когда под крылом что-то заметное.
- Раздел «Дальше» — обратный отсчёт до следующего места, границы, хребта.

### 8. Прилёт (40 с)

- Экран «демо-полёт завершён»: страны, места, увиденное.
- Опыт и уровень.
- Новые достижения.
- Викторина «насколько внимательно вы смотрели?».
- Открытка «Долетели».

В опубликованном демо демо-полёты засчитываются в паспорт: чем больше демо пролетите до записи, тем богаче будут «Атлас» и «Мой год». В сборке для App Store демо в паспорт не попадает.

### 9. Атлас и паспорт (30 с)

Вкладка «Атлас»:
- карта всех ваших полётов — дуги маршрутов, посещённые страны подсвечены;
- серия «N недель подряд в небе»;
- уровень, звание, опыт;
- штампы стран, коллекции, достижения;
- «Мой год в небе» — итоги: километры («0,3 оборота вокруг Земли»), часы, страны, карта года, самые яркие моменты.

### 9а. Люди (60 с)

Вкладка «Люди»:
- **Сейчас в небе** — друзья, которые летят прямо сейчас: маршрут, прогресс, страна внизу, сколько до посадки.
- **Рейтинг** по налёту, странам, местам или опыту — среди друзей, всех или за месяц. Пьедестал, ваше место («Ваше место — 9 412 из 18 426»).
- **Лента друзей:** рейсы с картой, новые страны, «своими глазами», достижения, серии, отзывы. Кнопка «браво».
- Нажмите на человека — его профиль: уровень, серия, карта полётов, страны, последние находки, «подписаться».

> «Те, кто летает каждую неделю, соревнуются по налёту и сериям, а друзья видят, кто сейчас в небе».

В демо люди и их полёты — пример: маршруты настоящие, сами люди придуманы. Внизу вкладки это написано. В приложении здесь будут настоящие друзья, когда подключим сервер.

### 9б. Отзывы на карточке места (15 с)

Внизу карточки места: «открыли 3 120 пассажиров», оценка, редкость, отзывы других пассажиров. Можно поставить звёзды и написать свой отзыв.

### 9в. Подписка Pro (10 с)

«Атлас» → «Настройки» → «SkyAtlas Pro»: тарифы «Поездка» и «Год». В демо купить нельзя, все функции открыты.

### 10. Добавить рейс (20 с, по желанию)

«Добавить рейс»:
- «откуда → куда» с поиском на любом из 6 языков;
- лента дат;
- время вылета;
- номер рейса и место — по желанию.

После «Готово» рейс собирается за секунду прямо на телефоне. На «Борте» видно:
- какое окно просить у стойки;
- лучшие моменты рейса;
- готовность офлайн.

## Чем веб-демо отличается от iPhone

| | iPhone | Веб-демо |
|---|---|---|
| Подложка карты | OpenStreetMap (OpenFreeMap): дороги, все города и посёлки, леса; рельеф и тени гор; всё офлайн по коридору рейса | Атлас Natural Earth: рельеф, реки, озёра, крупные и средние города, границы. Внешние тайлы на опубликованной странице запрещены |
| Фото Википедии | Скачиваются по Wi-Fi до вылета | В опубликованной версии нет: страница не может обращаться к внешним сайтам. Спутниковые снимки есть (встроены для 91 места на демо-маршрутах). При локальном запуске с интернетом фото Википедии появляются |
| Уведомления «слева Эльбрус через 5 минут» | На экране блокировки, в авиарежиме | Нет: браузер их не покажет |
| GPS у окна | Уточняет позицию самолёта | Нет |
| Скан посадочного, Wallet | Есть | Нет |
| Японский | Есть | Выключен (шрифты весят 16 МБ) |
| Люди, рейтинги, лента, отзывы | С сервером: настоящие друзья | Примерные люди на настоящих маршрутах (`EXPO_PUBLIC_DEMO_SOCIAL=1`) |
| Демо-полёт в паспорт | Не засчитывается | Засчитывается (`EXPO_PUBLIC_DEMO_COUNTS=1`) |
| Покупка Pro | Через App Store | Экран виден, покупки нет (`EXPO_PUBLIC_DEMO_PAYWALL=1`) |

## Локальный запуск (с интернетом — тогда видны фото Википедии)

```bash
git clone … && cd flyradar
npm install
cd apps/mobile
# Рельеф, атлас и спутниковые снимки для веба. Один раз; нужен интернет; файлы не хранятся в git.
node scripts/preview/fetch-dem.mjs
node scripts/preview/build-atlas.mjs
node scripts/content/satellite.mjs
npx expo start --web            # откроется http://localhost:8081
```

Собрать статическую версию, как опубликованная:

```bash
EXPO_PUBLIC_WEB_LINKING=off EXPO_PUBLIC_DEMO_SOCIAL=1 EXPO_PUBLIC_DEMO_COUNTS=1 EXPO_PUBLIC_DEMO_PAYWALL=1 \
  npx expo export --platform web --output-dir dist-web
npx serve dist-web
```

## На iPhone

Настоящее приложение ставится на iPhone из Xcode на Mac. Пошагово — `docs/IOS.md`. Коротко:

```bash
npm install
cd apps/mobile
scripts/xcode-demo.sh      # с бесплатным Apple ID: IOS_PERSONAL_TEAM=1 IOS_BUNDLE_ID=com.yourname.skyatlas scripts/xcode-demo.sh
```

Скрипт включает демо-режим, создаёт проект Xcode и открывает его. В Xcode: Signing & Capabilities → Team → выбрать iPhone вверху → ▶.

**Перед полётом:**
1. Добавьте рейс по Wi-Fi.
2. Дождитесь «готово офлайн» на «Борте» — скачаются истории, фото, карта и рельеф.
3. В самолёте нажмите «Взлетели».

Что ещё проверить на устройстве — `docs/QA_CHECKLIST.md`.
