# SkyAtlas — Продуктовый план

> Приложение для офлайн-отслеживания полёта и исследования мира с высоты птичьего полёта

---

## 1. Концепция и позиционирование

### Проблема
FlightRadar24 и аналоги не работают без интернета. Пассажир в самолёте не знает, где он находится, над чем летит, что за горы внизу, какой город справа по борту. Полёт — мёртвое время длиной 2–14 часов.

### Решение
SkyAtlas превращает полёт в интерактивное путешествие. До посадки в самолёт приложение скачивает всё необходимое: маршрут, карты, информацию о достопримечательностях вдоль пути. В воздухе — полный офлайн. Пассажир видит свою позицию на карте в реальном времени и получает контент о местах, над которыми пролетает.

### Целевая аудитория
- Путешественники (туристы, бизнес-пассажиры)
- Любопытные люди, которым интересна география
- Авиаэнтузиасты
- Родители с детьми на борту
- **Возраст:** 18–55 лет
- **Аудитория:** глобальная, с акцентом на English-speaking рынки

### Уникальное торговое предложение
Единственное приложение, которое работает офлайн и превращает полёт из скучного ожидания в исследование планеты.

## 2. Как это работает технически (простым языком)

### До полёта (онлайн)
1. Пользователь вводит номер рейса (например, SU100) или маршрут (SVO → JFK) — или сканирует посадочный талон камерой для автозаполнения
2. Приложение запрашивает данные: маршрут, расписание, время вылета
3. Скачивает офлайн-пакет: карты вдоль трека, все POI (точки интереса) в радиусе 300 км от маршрута, фото, статьи
4. Пакет занимает ~50–150 МБ

### В воздухе (офлайн)
- Позиция считается по формуле: `прошедшее время от взлёта / длительность рейса × маршрут`
- Маршрут — дуга большого круга (great circle route) между аэропортами
- Добавляется реалистичный профиль: набор высоты 30 мин → крейсер → снижение 40 мин
- Всё локально, без интернета

### Подтверждение времени взлёта — точность позиции
При открытии приложения в воздухе (если интернет уже недоступен) появляется диалог: **"Подтвердите фактическое время взлёта"**. Пользователь вводит реальное время отправления — это устраняет дрейф позиции, накапливающийся из-за задержек рейса и изменений маршрута. Даже 20-минутная задержка на земле без этой коррекции даёт погрешность ~300 км на длинных маршрутах.

## 3. Функциональность

### 3.1 Ядро — Офлайн-трекинг

| Функция | Описание |
|---|---|
| Карта в реальном времени | Позиция самолёта на офлайн-карте |
| Маршрут | Визуализация пройденного пути и оставшегося |
| Текущие параметры | Расчётная скорость (~900 км/ч), высота (~10 000 м), курс |
| Время до прилёта | Оставшееся время и расстояние |
| Часовой пояс | Текущий часовой пояс под бортом |
| Рассвет/закат | Время рассвета и заката в точке под самолётом |
| Смена стран | Уведомление при пересечении границы |

### 3.2 Исследование мест — главная фишка

Когда самолёт проходит в радиусе N км от интересного объекта, появляется карточка:

**Категории объектов:**
- 🏙️ Города (население, страна, интересный факт)
- ⛰️ Горы и хребты (высота, название, первовосхождение)
- 🌊 Океаны, моря, озёра, реки
- 🌋 Вулканы
- 🏛️ Исторические объекты (пирамиды, замки, руины)
- 🌿 Национальные парки и заповедники
- 🏝️ Острова
- 🌉 Инженерные сооружения (дамбы, мосты)
- 🗻 Природные феномены

**Карточка объекта содержит:**
- Название и тип
- Расстояние от борта (сейчас / максимальное сближение)
- 2–3 фотографии
- 300–500 слов интересного текста (не Википедия копипаста — адаптированный)
- 3–5 wow-фактов ("Это озеро содержит 20% мировых запасов пресной воды")
- Интерактивная мини-карта с объектом

**Пример UX:**
> "Через 4 минуты вы будете пролетать над Байкалом — самым глубоким озером в мире. Глубина — 1642 м, это глубже, чем высота Эйфелевой башни × 5..."

### 3.3 Killer-features

**Сканирование посадочного талона (Boarding Pass Scan)**
Пользователь наводит камеру на посадочный талон → приложение автоматически распознаёт номер рейса, маршрут и время вылета → рейс добавляется без ручного ввода. Критично для UX: снижает барьер входа до нуля.

**AR-режим — "Что это за место?"**
Пользователь наводит камеру на иллюминатор → на экране появляются подписи ближайших объектов с расстоянием в реальном времени: горные вершины, города, реки, озёра. Виральная фича: люди снимают видео и делятся в соцсетях.

**Виджет на Lock Screen (iOS / Android)**
На экране блокировки постоянно отображается: текущая позиция самолёта, "Сейчас над: Польша", время до прилёта. Работает без открытия приложения — максимальная видимость и удобство.

### 3.4 Статистика полёта

Живая инфографика прямо в полёте:
- Пройдено км / осталось км
- Стран пролетели над
- Объектов обнаружено
- "За бортом сейчас −57°C"
- "Вы летите быстрее пули в 3 раза"
- "Под вами сейчас 9 840 м до земли"

### 3.5 Итоги полёта — экран по прилёту

После приземления красивый summary:
- Маршрут на карте с пройденным треком
- Все открытые объекты
- Страны над которыми пролетел
- Расстояние, время в воздухе
- Новые достижения
- Кнопка "Поделиться"

## 4. Геймификация

### 4.1 Коллекции

**Страны** — список стран, над которыми пролетал. Карта мира заполняется цветом.

**Континенты** — пересёк Атлантику? Получи метку.

**Природные чудеса** — 7 природных чудес света, специальные карточки при пролёте.

**Горные вершины** — восьмитысячники, Альпы, Анды, Кавказ.

**Моря и океаны** — коллекция пересечённых водоёмов.

### 4.2 Достижения (Achievements)

| Достижение | Условие |
|---|---|
| 🌍 Первый полёт | Открыть первый рейс |
| ✈️ Воздушный волк | 10 рейсов |
| 🌏 Кругосветчик | Рейсы на всех 6 обитаемых континентах |
| 🌊 Покоритель Атлантики | Трансатлантический рейс |
| 🏔️ Над Гималаями | Пролететь над Непалом/Тибетом |
| 🌋 Огненный пояс | Пролететь над 3 вулканами |
| 🌙 Ночной охотник | 5 ночных рейсов |
| ⏰ Марафонец | Рейс длиннее 12 часов |
| 🌅 Охотник за рассветом | Встретить рассвет в воздухе |
| 🗺️ Исследователь | Открыть 50 объектов |
| 📚 Знаток | Прочитать 100 карточек объектов |
| 🏆 Легенда неба | 100 рейсов |

### 4.3 Уровни и прогресс

- Уровень путешественника (1–100) на основе км налёта
- Ранги: Новичок → Путешественник → Исследователь → Первооткрыватель → Легенда
- XP за каждый рейс, за открытые объекты, за прочитанные карточки

### 4.4 Статистика за всё время

- Суммарный налёт (км, часы)
- Стран в коллекции
- Объектов открыто
- Самый длинный рейс
- Любимый маршрут
- Карта мира с треками всех полётов

### 4.5 Вирусный луп — "Лети вместе"

**"Лети вместе":** Пригласи друга добавить тот же рейс → оба получают SkyAtlas Pro на этот рейс бесплатно. Механика работает на борту: двое летят вместе и оба открывают Premium-фичи без оплаты — это создаёт совместный опыт и знакомит с продуктом в лучший момент.

**Referral-программа:** Пригласи друга → он совершает первую покупку → ты получаешь 1 бесплатный рейс на счёт. Низкие затраты на привлечение, высокая мотивация делиться.

### 4.6 Шеринг

- Красивые карточки для Instagram/Twitter: "Только что пролетел над Альпами"
- Трек полёта на карте мира
- Итоги года (как Spotify Wrapped, только для полётов)

## 5. Контент и данные

### Источники данных

| Источник | Что берём | Стоимость |
|---|---|---|
| OpenSky Network | История треков рейсов, маршруты | Бесплатно |
| AviationStack | Расписание, номера рейсов | Free tier (1000 req/мес) |
| OpenFlights.org | База аэропортов и маршрутов | Бесплатно |
| GeoNames | 11M+ географических объектов | Бесплатно |
| Wikipedia API | Тексты, факты, фото | Бесплатно |
| Unsplash API | Фотографии мест | Бесплатно (с attribution) |
| Natural Earth | Границы стран, топография | Бесплатно |
| MapLibre + OpenStreetMap | Офлайн-карты | Бесплатно |

### Качество контента

На старте — автоматически агрегированный контент из Wikipedia + GeoNames.
По мере роста — собственная редакция: адаптированные тексты, wow-факты, curated фотографии.
Долгосрочно — AI-генерация персонализированного контента (интересы пользователя).

## 6. Монетизация

### 6.1 Модель: Freemium + Per-Flight

**Бесплатно (Free):**
- Офлайн-трекинг (позиция, карта, параметры полёта)
- До 5 карточек объектов за рейс
- Базовая статистика полёта
- 3 достижения
- История последних 3 рейсов

**Премиум (SkyAtlas Pro):**
- Безлимитные карточки объектов
- Все достижения и коллекции
- Полная история рейсов
- Карта мира со всеми треками
- Итоги года
- Расширенные статьи и больше фото
- Офлайн-карты в высоком разрешении
- Приоритетная загрузка пакетов
- AR-режим и Lock Screen виджет

### 6.2 Ценообразование

| Тариф | Цена | Модель |
|---|---|---|
| Per-Flight | $1.99 / рейс | Разовая покупка |
| Annual | $19.99/год (~$1.67/мес) | Подписка |
| Lifetime | $49.99 | Разовая покупка |

**Логика конверсионной воронки:**
Пользователь летит → видит Free-ограничения (5 карточек) → покупает один рейс за $1.99 (низкий барьер) → убеждается в ценности продукта → переходит на Annual $19.99. Per-Flight намеренно прибыльный сам по себе и одновременно служит trial-механикой для Annual.

### 6.3 Дополнительные источники дохода

**B2B — Авиакомпании:**
- Белая метка (white label) для авиакомпаний: их брендинг, их маршруты
- Интеграция в IFE (in-flight entertainment) системы
- Стоимость: $10K–50K/год за авиакомпанию

**Партнёрства:**
- Travel-страховки (показываем предложение при добавлении рейса)
- Туристические гиды (ссылки на Lonely Planet, GetYourGuide)
- Отели в городе прибытия

**Реклама (только для free-пользователей):**
- Нативная реклама в карточках объектов (путешествия, отели)
- Без агрессивных баннеров

### 6.4 Прогноз монетизации

Консервативный сценарий (через 1 год):
- 100 000 загрузок
- 5% покупают Per-Flight = 5 000 транзакций × $1.99 = **$9 950**
- 2% переходят на Annual = 2 000 × $19.99 = **$39 980**
- Итого: ~**$50 000 ARR**

Оптимистичный (через 2 года):
- 1M загрузок, рост конверсии за счёт Per-Flight воронки
- **$1M ARR**

## 8. Технологический стек

### Мобильное приложение
- **React Native + Expo** — кросс-платформа iOS + Android, быстрая разработка
- **MapLibre GL** — офлайн-карты (open source, бесплатно)
- **SQLite** — локальное хранение данных рейсов и POI
- **React Native MMKV** — быстрое хранилище настроек
- **MLKit / Vision** — распознавание посадочных талонов (OCR/barcode)
- **ARKit / ARCore** — AR-режим (iOS / Android)

### Бэкенд
- **Node.js + Fastify** (или Python + FastAPI) — API сервер
- **PostgreSQL + PostGIS** — геопространственные данные (POI, маршруты)
- **Redis** — кэш популярных маршрутов
- **S3-совместимое хранилище** — фото, офлайн-пакеты

### Инфраструктура
- **AWS / Hetzner** — хостинг (Hetzner дешевле для старта)
- **Cloudflare** — CDN для офлайн-пакетов
- **RevenueCat** — управление подписками и разовыми покупками (iOS + Android в одном)

### Внешние API
- OpenSky Network, AviationStack, Wikipedia, GeoNames, Unsplash

## 10. Ключевые риски и митигация

| Риск | Вероятность | Митигация |
|---|---|---|
| Неточность позиции | Средняя | Подтверждение времени взлёта пользователем; допустимая погрешность ±50 км на длинных маршрутах |
| Качество контента поначалу низкое | Высокая | Фокус на топ-500 популярных маршрутов; ручная редактура для них |

| AR не работает стабильно | Средняя | Запускать AR как beta, не как core-фичу |

## 11. Что делает приложение залипательным

1. **Эффект открытия** — пролетел над чем-то — узнал что-то новое. Мозг любит открытия.
2. **Коллекционирование** — карта стран заполняется, это визуально приятно.
3. **FOMO** — "что я пропустил?" → смотрит историю → вовлечение.
4. **Социальное доказательство** — поделился карточкой "Я летел над Альпами" → виральность.
5. **Прогресс** — уровни, XP, ранги → хочется летать ещё.
6. **Уникальность** — контент генерируется твоим конкретным маршрутом, нет двух одинаковых полётов.
7. **AR-вау-момент** — снял видео через иллюминатор с подписями → сразу делишься → органический рост.
8. **"Лети вместе"** — совместный опыт с другом на борту создаёт эмоциональную связь с продуктом.
