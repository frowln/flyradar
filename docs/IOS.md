# SkyAtlas на iPhone через Xcode

*Как поставить настоящее приложение на свой iPhone для демо. Примерно 20 минут в первый раз, дальше — одна кнопка.*

SkyAtlas — iOS-приложение на React Native (Expo). Папка `ios/` с проектом Xcode не хранится в git: её создаёт команда `expo prebuild` из `app.json`. Так проект всегда совпадает с кодом.

## Что нужно

| | |
|---|---|
| Mac | macOS 15 или новее |
| Xcode | Последний из App Store. При первом запуске согласитесь поставить iOS-платформу |
| Node.js | 20.19 или новее: `brew install node@20` или с nodejs.org |
| CocoaPods | `brew install cocoapods` |
| iPhone | iOS 16 или новее, кабель |
| Apple ID | Подойдёт и бесплатный. С ним приложение работает 7 дней, потом нажмите ▶ в Xcode ещё раз |

## Шаги

**1. Код**

```bash
git clone https://github.com/frowln/flyradar.git
cd flyradar
git checkout claude/brave-thompson-2y40re
npm install
cd apps/mobile
```

**2. Проект Xcode**

Платный аккаунт разработчика:

```bash
scripts/xcode-demo.sh
```

Бесплатный Apple ID — замените `yourname` на любое своё слово латиницей:

```bash
IOS_PERSONAL_TEAM=1 IOS_BUNDLE_ID=com.yourname.skyatlas scripts/xcode-demo.sh
```

Скрипт:
- включает демо-режим: примерные люди во вкладке «Люди», демо-полёты засчитываются в паспорт, виден экран Pro;
- создаёт проект и ставит зависимости (CocoaPods, 3–5 минут);
- открывает Xcode.

При бесплатном Apple ID скрипт убирает то, что такому аккаунту недоступно: push-уведомления с сервера и вход через Apple. Локальные напоминания работают.

**3. Подпись**

В Xcode:
1. Слева нажмите на синий значок **SkyAtlas**.
2. Вкладка **Signing & Capabilities** → **Team**.
3. Выберите свой Apple ID. Если его нет — **Add an Account…**.

**4. iPhone**

1. Подключите iPhone кабелем, разблокируйте, нажмите «Доверять».
2. Включите режим разработчика: **Настройки → Конфиденциальность и безопасность → Режим разработчика** (iOS 16+). Телефон перезагрузится.
3. В Xcode вверху, рядом с SkyAtlas, выберите свой iPhone.

**5. Запуск — ▶ (⌘R)**

Первая сборка идёт 5–10 минут, следующие — около минуты. Сборка Release: приложение работает само, без Mac рядом, на полной скорости.

С бесплатным Apple ID при первом запуске iPhone скажет «Ненадёжный разработчик». Разрешите: **Настройки → Основные → VPN и управление устройством** → ваш Apple ID → «Доверять».

## Что показать

Сценарий записи — `docs/DEMO.md`, раздел «Сценарий записи». Запись экрана iPhone: Пункт управления → ⏺.

Карта полёта:
- Приближайте и отдаляйте двумя пальцами: самолёт остаётся в центре, карта следует за ним.
- Сдвиньте карту пальцем, чтобы посмотреть в сторону. Появится кнопка **◎ к самолёту**: карта вернётся и снова поедет за самолётом.
- «Во весь экран» и «ночная / рельеф» — кнопки в углу карты.

На iPhone карта подробнее, чем в браузере: дороги, все города и посёлки, леса, рельеф. Подписи на языке телефона.

## Симулятор (без iPhone)

В Xcode вверху выберите любой iPhone из списка Simulators → ▶.

Без Mac: GitHub собирает приложение в Xcode на своём Mac и пролетает демо в симуляторе iPhone. Это делает файл `.github/workflows/ios.yml`, если сообщение коммита начинается с `[ios]`. Видео полёта, скриншоты и сборка для симулятора лежат в артефактах прогона: вкладка **Actions** → прогон **iOS** → **Artifacts**.

## Если что-то не так

| Ошибка | Что делать |
|---|---|
| `No signing certificate` / `Signing requires a development team` | Шаг 3: выберите Team |
| `Failed to register bundle identifier` | Этот id занят: запустите скрипт с другим `IOS_BUNDLE_ID` |
| `Personal development teams do not support…` | Запустите скрипт с `IOS_PERSONAL_TEAM=1` |
| `pod install` падает | `brew install cocoapods`, затем скрипт ещё раз |
| Белый экран, «No bundle URL present» | Сборка Debug ждёт сервер Metro. Запустите скрипт заново (он ставит Release) или выполните `npx expo start` в соседнем окне |
| Карта пустая | Нужен интернет при первом показе маршрута. В полёте карта работает офлайн, если рейс подготовлен по Wi-Fi |
