# SkyAtlas на Mac и iPhone через Xcode

*Как запустить настоящее iOS-приложение у себя и записать демо. Первый раз — 20–40 минут, в основном ожидание сборки; дальше — минута.*

SkyAtlas — iOS-приложение на React Native (Expo). Папка `ios/` с проектом Xcode не хранится в git: её создаёт `expo prebuild` из `app.json`, поэтому проект всегда совпадает с кодом. Всё это делает один скрипт.

Три пути:
- **Видео само** — одна команда собирает приложение, проходит всю экскурсию в симуляторе iPhone и кладёт видео на рабочий стол. Ничего нажимать не нужно.
- **Симулятор iPhone на Mac** — нажимаете сами: не нужен ни iPhone, ни Apple ID.
- **Свой iPhone** — для записи на живом телефоне. Нужен Apple ID, подойдёт бесплатный.

## 1. Один раз: что поставить на Mac

| | Как поставить |
|---|---|
| Xcode | Из App Store. Откройте один раз, согласитесь поставить компоненты и iOS-платформу |
| Homebrew | С сайта brew.sh, одна команда в Терминале |
| Node.js 20.19+ | `brew install node@20` |
| CocoaPods | `brew install cocoapods` |

Если чего-то не хватает, скрипт из шага 3 сам скажет, что и какой командой поставить.

## 2. Код

В Терминале:

```bash
git clone https://github.com/frowln/flyradar.git
cd flyradar
git checkout claude/brave-thompson-2y40re
cd apps/mobile
```

Репозиторий закрытый: при `git clone` GitHub спросит вход. Проще всего войти через GitHub Desktop или `brew install gh && gh auth login`.

## 3. Видео само — одной командой

```bash
scripts/record-demo.sh
```

Скрипт:
1. проверит, всё ли стоит, и поставит робота Maestro и ffmpeg (для Maestro нужна Java: `brew install --cask temurin`, скрипт скажет);
2. соберёт приложение в Xcode (первый раз 15–25 минут);
3. откроет симулятор iPhone и сам пройдёт экскурсию: онбординг, полёт Москва → Сочи с картой (приближение, «к самолёту», спутник, 3D, весь маршрут, ночь), панель, вид из окна, карточку места, посадку, «Атлас», «Мой год», достижения, настройки, Pro, «Люди», профиль;
4. положит видео на рабочий стол: `SkyAtlas-demo.mp4`, рядом — папку со скриншотами и отчётом, какие части прошли.

Пока идёт запись, окно симулятора лучше не трогать. Если где-то будет «Что-то сломалось» — это попадёт в видео и в скриншоты вместе с текстом ошибки: пришлите их.

## 3а. Симулятор iPhone (без iPhone и Apple ID)

```bash
scripts/xcode-demo.sh sim
```

Первая сборка — 10–20 минут. Потом откроется окно Simulator с iPhone, и приложение запустится само.

- **Язык.** В приложении: «Атлас» → «Настройки» → «Язык». Или в самом симуляторе: Settings → General → Language & Region.
- **Запись видео:** в окне Simulator — **File → Record Screen** (⌘R). Остановить — тем же пунктом. Видео сохранится на рабочий стол.
- **Жесты.** Приблизить карту двумя пальцами — зажмите ⌥ Option и ведите мышью. Удобнее кнопками «+ / −» на карте.

Перезапустить после изменений в коде — та же команда, повторная сборка занимает пару минут.

## 3б. Свой iPhone

Платный аккаунт разработчика:

```bash
scripts/xcode-demo.sh
```

Бесплатный Apple ID — замените `yourname` на любое своё слово латиницей:

```bash
IOS_PERSONAL_TEAM=1 IOS_BUNDLE_ID=com.yourname.skyatlas scripts/xcode-demo.sh
```

Скрипт создаст проект, поставит CocoaPods (3–5 минут) и откроет Xcode. При бесплатном Apple ID он уберёт то, что такому аккаунту недоступно: push с сервера и вход через Apple. Локальные напоминания работают.

Дальше в Xcode:
1. Слева нажмите на синий значок **SkyAtlas** → вкладка **Signing & Capabilities** → **Team** → ваш Apple ID. Если его нет — **Add an Account…**.
2. Подключите iPhone кабелем, разблокируйте, нажмите «Доверять».
3. На iPhone включите режим разработчика: **Настройки → Конфиденциальность и безопасность → Режим разработчика**. Телефон перезагрузится.
4. В Xcode вверху, рядом с SkyAtlas, выберите свой iPhone и нажмите **▶** (⌘R).

Первая сборка — 5–10 минут, следующие — около минуты. Сборка Release: приложение работает само, без Mac рядом.

С бесплатным Apple ID при первом запуске iPhone скажет «Ненадёжный разработчик». Разрешите: **Настройки → Основные → VPN и управление устройством** → ваш Apple ID → «Доверять». Такая установка работает 7 дней, потом снова ▶ в Xcode.

Запись экрана на iPhone: Пункт управления → ⏺.

## 4. Что показать

Сценарий записи — `docs/DEMO.md`, раздел «Сценарий записи». Начало: «Борт» → «Или выберите, куда лететь» → «Москва → Сочи».

Карта полёта:
- Приближайте кнопками **+ / −** или двумя пальцами: самолёт остаётся в центре.
- Сдвиньте карту пальцем — появится **«◎ к самолёту»**.
- Внизу переключатель **рельеф · спутник · ночь**.
- **3D** — камера за самолётом, по курсу.
- Значок маршрута — весь путь целиком.
- **«Во весь экран»** — карта на весь экран, внизу плашка: осталось (время и км), высота, скорость, температура за бортом.

На iPhone карта подробнее, чем в браузере: дороги, все города и посёлки, леса. Подписи на языке приложения.

## 5. Что уже проверено на iPhone

На симуляторе iPhone 17 Pro (iOS 26) робот прошёл: онбординг, полёт Москва → Сочи, карту (приближение, «к самолёту», рельеф, спутник, 3D, весь маршрут, ночь, плашку во весь экран), ползунок момента полёта, панель и вид из окна, посадку, «Атлас», «Мой год», достижения, настройки, Pro, «Люди» и профиль. Скриншоты — в `docs/ios-simulator/`.

Карточку места из панели робот не открыл: проверьте её руками — нажмите на строку места в панели.

Если появится экран «Что-то сломалось», под ним будет красный текст ошибки. Сфотографируйте или сделайте скриншот (на Mac — ⌘⇧4) и пришлите: этого хватит, чтобы исправить. Текст ошибки показывается только в этой тестовой сборке.

## Если что-то не так

| Ошибка | Что делать |
|---|---|
| Скрипт пишет, чего не хватает | Выполните команду, которую он предлагает, и запустите скрипт снова |
| `No signing certificate` / `Signing requires a development team` | Шаг 3б, пункт 1: выберите Team |
| `Failed to register bundle identifier` | Этот id занят: запустите скрипт с другим `IOS_BUNDLE_ID` |
| `Personal development teams do not support…` | Запустите скрипт с `IOS_PERSONAL_TEAM=1` |
| `pod install` падает | `brew install cocoapods`, затем `pod repo update` и скрипт ещё раз |
| «Не скачивается движок Hermes» или `Unable to locate the executable cmake` | Скрипт сам берёт Hermes с зеркала Google, если основной сервер не отвечает. Если не помогло — включите или выключите VPN и запустите снова. cmake ставить не нужно |
| Белый экран, «No bundle URL present» | Это сборка Debug, ей нужен сервер Metro. Запустите скрипт заново (он ставит Release) |
| Карта пустая | Нужен интернет при первом показе маршрута. В полёте карта работает офлайн, если рейс подготовлен по Wi-Fi |
| Что-то другое | Пришлите последние строки из Терминала или скриншот ошибки из Xcode (вкладка с красным крестиком слева) |

## Без Mac: сборка на GitHub

`.github/workflows/ios.yml` собирает приложение в Xcode на маковском сервере GitHub и проходит демо в симуляторе, если сообщение коммита начинается с `[ios]`. Скриншоты, видео и журнал попадают в `docs/ios-simulator/`. Видео собирается из снимков экрана с точным временем каждого: собственная запись симулятора на сервере GitHub путает время. Минута маковского сервера в закрытом репозитории стоит как 10 обычных: бесплатных минут хватает на несколько прогонов в месяц.
