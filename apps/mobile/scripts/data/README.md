# Offline datasets

The app ships four JSON files in `apps/mobile/assets/data/`, so a flight can be
prepared and followed with no network at all. Their shapes are the contract in
`src/core/data/types.ts`; the files are generated by the scripts in this folder
and never edited by hand.

| File | Type | Contents |
| --- | --- | --- |
| `airports.json` | `AirportsFile` | ~4 000 airports with an IATA code and scheduled service |
| `places.json` | `PlacesFile` | ~9 300 things seen from a window: cities, peaks, volcanoes, ranges, deserts, seas, lakes, rivers, islands, glaciers … |
| `areas.json` | `AreasFile` | simplified outlines of the area places, keyed by place id |
| `countries.json` | `CountriesFile` | ~260 country / territory outlines with ISO codes |

## Regenerating

Node ≥ 20, no npm packages. Downloads go through `curl` (which honours
`HTTPS_PROXY`) into `scripts/data/.cache/` (git-ignored, ~90 MB); later runs
reuse the cache. Run from `apps/mobile`:

```sh
node scripts/data/build-countries.mjs   # first: airports and places use it for country codes
node scripts/data/build-airports.mjs
node scripts/data/build-places.mjs      # writes places.json and areas.json
node scripts/data/validate.mjs          # exits 1 on any problem
```

- `--refresh` on any builder re-downloads its inputs (sources move on daily for
  OurAirports; Natural Earth is read from its `master` branch, override with
  `NE_REF=v5.1.2` etc.).
- `DEBUG=1` for `build-places.mjs` logs every duplicate it merges.

`validate.mjs` checks types and ranges, unique ids / IATA / ISO codes,
coordinate bounds, rings of ≥ 3 distinct points without a repeated closing
point, outlines inside their `bb`, label points inside their outline,
cross-file references (every place `cc` and airport `cc` exists in
`countries.json`, every area place has an outline and vice versa), a few
point-in-country facts (central Moscow → RU, Singapore → SG, Valletta → MT,
Manama → BH, Vatican → VA, Paris, New York, Cayenne → GF, Tokyo, and the
disputed areas: Simferopol and Sevastopol → XR, Laayoune → EH, Rabat → MA,
Kyiv and Kherson → UA, Pristina → XK, north Nicosia → XC, Hargeisa → XS) and the size
budgets (airports 1.2 MB, places 3 MB, areas 2.5 MB, countries 2 MB).

## Airports (`build-airports.mjs`)

- Kept: OurAirports rows with a 3-letter IATA code, `scheduled_service = yes`
  and type `large_airport` (`s: 3`), `medium_airport` (`s: 2`) or
  `small_airport` (`s: 1`). One row per IATA code (the larger type wins).
  Airports that lost scheduled service (e.g. Kyiv, Lviv, Odesa while Ukrainian
  airspace is closed) are therefore absent until OurAirports flags them again.
- `c`: ICAO code (`icao_code`, else a 4-letter `gps_code` / ident).
- `tz`: mwgg/Airports by ICAO, then by IATA (ignored if its position is > 1°
  off); otherwise the zone of the nearest mwgg airport, same country first.
  Every zone is checked with `Intl.DateTimeFormat`. Zones renamed in recent
  tzdata (`Europe/Kyiv`, `America/Nuuk`, `Pacific/Kanton`) are written under
  their older names, which every tz database resolves (older Android ICU does
  not know the new ones).
- `city`, `cl`: the municipality (and mwgg's city) is matched against Natural
  Earth populated places within 40 km on ASCII-folded names (exact, whole-word
  prefix like "Frankfurt am Main" ~ "Frankfurt", or 1–2 typos); an exact name of
  a city over 1 M people may be up to 80 km away (Domodedovo → Moscow, Narita →
  Tokyo). On a match, `city` is Natural Earth's English name and `cl` its
  translations; otherwise `city` is the municipality as OurAirports spells it
  and there is no `cl`.
- `cc`: OurAirports `iso_country` (ISO 3166-1), except that an airport inside a
  disputed area takes that area's code from `countries.json` (see *Disputed
  areas*): Ercan `CY` → `XC`, Hargeisa and Berbera `SO` → `XS`; Laayoune, Dakhla
  and Smara are `EH` and Pristina `XK` in OurAirports already. Needs
  `countries.json`, so build countries first.

## Places (`build-places.mjs`)

| Layer (Natural Earth 1:10m) | Kinds | Id prefix | Kept |
| --- | --- | --- | --- |
| populated_places | `city`; research stations and historic places → `landmark` | `ne-pp-` | population ≥ 100 000, national capitals, or scalerank ≤ 7 |
| geography_regions_elevation_points | `mountain`, `volcano`; depressions → `region`; passes, ice-dome stations → `landmark` | `ne-pk-` | named |
| geography_regions_polys | ranges and foothills → `range`; `desert`; `plateau`; peninsulas, capes, isthmuses → `peninsula`; islands and island groups → `island`; lakes → `lake`; gorges → `landmark`; plains, basins, valleys, deltas, wetlands, tundra, coasts, other named areas → `region` | `ne-rg-` | all but continents |
| geography_regions_points | islands → `island`; capes, waterfalls → `landmark`; plains → `region` | `ne-rg-` | all but the (2005) magnetic poles |
| geography_marine_polys | oceans, seas, gulfs, bays, straits, channels, sounds, fjords, lagoons → `sea`; reefs → `landmark` | `ne-mr-` | named |
| lakes | `lake` | `ne-lk-` | named |
| rivers_lake_centerlines (shapefile: the GeoJSON export lacks translations and wikidata ids) | `river` | `ne-rv-` | named rivers with scalerank ≤ 6 and ≥ 30 km |
| glaciated_areas | `glacier` (English names only, no wikidata in the source) | `ne-gl-` + name slug | named |

- **Ids** are the Natural Earth `ne_id` of the feature (for merged features, of
  the largest one); Natural Earth reuses a few ids for distinct features, the
  later ones get a `-2` suffix.
- **Names**: `n` is `name_en` (title-cased when Natural Earth has it in capitals;
  for lakes the fuller `name` when `name_en` dropped the "Lake"; one-word river
  names get " River": "Yellow River"). For cities `n` is Natural Earth's `NAME`
  unless `name_en` is a close spelling of it (see `neCityNames` in `lib.mjs`:
  the Wikidata-derived fields of a city are only used when they agree with its
  name, because a few are linked to the wrong item). `l` holds `name_ru/de/fr/es/ja`
  that differ from `n`.
- **Merging within a layer**: features with the same wikidata id (else the same
  name) that lie within 300 km of each other become one place with a
  MultiPolygon outline (the North and South Pacific, the pieces of an ice
  sheet). River segments merge by wikidata id (up to 1 000 km apart, across
  lakes) or by name when they touch.
- **Dedupe across layers**: same wikidata id within 100 km (never merging a city
  into a non-city), or same name and kind within 30 km (or inside a small
  area's bbox), keep one: rivers beat estuary polygons, outlines beat points,
  then higher `r`; the survivor takes the higher `r` and missing `wd` / `l` /
  `el` / `pop`. A wikidata id still shared by places more than 50 km apart is a
  Natural Earth linking error and is dropped from all of them.
- **Volcanoes**: Natural Earth has no volcano class; peaks named "… Volcano",
  "Volcán …", "… Sopka" and a curated list of well-known volcanoes in its
  elevation layer (`VOLCANOES` in `build-places.mjs`) get `volcano`.
- **Label point** (`lat`/`lon`): points as given; areas use the pole of
  inaccessibility of their largest simplified polygon, so it is inside the
  shipped outline; rivers use the midpoint (by length) of their longest part.
- **`cc`**: point-in-polygon against `countries.json` (cities and islands may be
  up to 15 km outside a simplified coastline, peaks 10 km); extents get a code
  only when ≥ 90 % of their sampled outline / line vertices that fall on land
  are in one country (island groups: ≥ 90 % of the country vertices inside the
  group's outline). Seas and places spanning several countries have none.
- **`ext`**: half the larger side of the feature's bounding box, in km (rivers:
  half their total length). **`bb`**: bounding box of the shipped outline
  (rivers: of the line), rounded outwards to 0.01°.

### Importance `r` (1–10)

Every place gets a Natural Earth rank score `q` and, where it has one, a
magnitude score `m`:

- `q` (physical layers) = `9 − scalerank`, +1 when Natural Earth labels the
  feature already at world zoom (`min_label` / `min_zoom` ≤ 2); for cities
  `q = 10 − scalerank`. Elevation points with scalerank > 7 (country high points
  added from PeakBagger) get `q = 1`.
- `m`: cities by population (≥ 15 M: 9, 7 M: 8, 3 M: 7, 1 M: 6, 500 k: 5,
  250 k: 4, 100 k: 3, 30 k: 2, else 1); peaks by elevation (≥ 8 000 m: 8,
  7 000: 7, 6 000: 6, 5 000: 5, 4 000: 4, 3 000: 3, 1 500: 2, else 1); areas
  `round(1.2·log10(km²) − 0.6)` clamped to 1–9 (100 km² → 2, 10 000 → 4,
  1 M → 7, 10 M → 8); rivers `round(2·log10(length km) − 1)` clamped to 1–8.

Then:

- cities, peaks: `r = max(q, m)`; national capitals at least 6; research
  stations / historic places `q − 1`;
- areas and rivers: `r = min(max(q, m), m + 3)` — the rank may lift a feature
  at most 3 above what its size says (so Lake St. Clair, scalerank 0 as part of
  the Great Lakes system, is not a 9);
- other points: `r = q`;
- a short editorial list of world-famous features that Natural Earth ranks low
  or that tie with lesser ones is set to 10 (`FAMOUS` in `build-places.mjs`:
  Everest, K2, Mont Blanc, Matterhorn, Kilimanjaro, Fuji, Vesuvius, Etna,
  Sahara, Gobi, Alps, Himalayas, Andes, Rockies, Mediterranean, Caspian,
  Baikal, Dead Sea, Amazon, Nile, Great Barrier Reef, Niagara, Victoria and
  Iguaçu Falls, Grand Canyon, Greenland).

Result: r 10 ≈ 60 places (oceans, the 27 Natural Earth "scalerank 0" world
cities, the list above), r 9 ≈ 90, r 8 ≈ 160, r 7 ≈ 540, and most small
cities at 3–4.

## Geometry

- Coordinates are `[lon, lat]`, rings open (first point not repeated), outer
  ring then holes. Points are rounded to 3 decimals (~100 m), outlines to 2
  (~1 km) after Douglas–Peucker simplification; rings that would collapse at
  that precision keep up to 2 more decimals.
- Area outlines: tolerance = feature size / 200 (regions, seas), / 120 (lakes),
  / 60 (glaciers), between 0.01° and 0.1°; islets under 0.2 % and holes under
  1 % of the feature's area are dropped.
- Countries: tolerance 0.03° (> 1 M km²), 0.018° (> 100 000 km²), 0.01°
  (> 30 000 km²), else 0.003° with 3 decimals; a ring's tolerance never
  exceeds 8 % of its narrower side, so narrow islands (Manhattan) keep their
  shape. Countries over 50 000 km² drop islets under 20 km²; smaller ones keep
  every islet. Holes are kept (Italy's are the Vatican and San Marino). Borders
  are simplified per country, not topologically, so neighbours can overlap or
  leave slivers of up to ~1–2 km along a border.
- **Rivers have no outline** in `areas.json` (they are lines, and the contract
  only has polygons): a river is its label point, `ext` (half its length) and
  `bb`.
- **Antimeridian**: features crossing ±180° (Russia, Fiji, the Pacific, the
  Bering Sea, Antarctica …) have `bb = [-180, minLat, 180, maxLat]`, so a plain
  `minLon ≤ lon ≤ maxLon` test never misses them; their `ext` is computed on the
  real (wrapped) longitude span. Natural Earth already splits their polygons at
  ±180°.

## Countries (`build-countries.mjs`)

One entry per code. `cc` is `ISO_A2`, else `ISO_A2_EH`, with these exceptions:

| Natural Earth | Code |
| --- | --- |
| Kosovo | `XK` |
| N. Cyprus | `XC` (pseudo) |
| Somaliland | `XS` (pseudo) |
| Akrotiri + Dhekelia (UK bases on Cyprus) | `XD` (pseudo, one entry) |
| Crimea (see below) | `XR` (pseudo) |
| Western Sahara, whole territory (see below) | `EH` |
| Siachen Glacier / S. Patagonian Ice Field / Bir Tawil / Spratly Is. / Scarborough Reef / Bajo Nuevo / Serranilla | `XG` / `XP` / `XT` / `XU` / `XB` / `XN` / `XE` (pseudo) |
| Clipperton I. | `CP` (ISO exceptionally reserved) |
| Cyprus UN buffer zone, Guantanamo Bay, Baikonur, Brazilian I., Coral Sea Is., Ashmore and Cartier Is. | merged into `CY`, `CU`, `KZ`, `BR`, `AU`, `AU` |
| Indian Ocean Ter. | split into `CX` Christmas Island and `CC` Cocos (Keeling) Islands |
| France: French Guiana, Guadeloupe, Martinique, Réunion, Mayotte | split out as `GF`, `GP`, `MQ`, `RE`, `YT` (airports there carry these ISO codes) |
| Netherlands: Bonaire, Sint Eustatius, Saba | split out as `BQ` |

`cont` is Natural Earth's `CONTINENT`; its "Seven seas (open ocean)" islands
use the UN region (Heard Island → Oceania, South Georgia → South America,
Mauritius → Africa …). Names for split / merged entries are set in the script.

### Disputed areas

**Policy: disputed areas are shown as regions of their own, without
attributing them to a state.** A flight over one earns that region's stamp,
not a country's. Places and airports inside one carry its code.

| Area | Entry | How it is built |
| --- | --- | --- |
| Crimea (incl. Sevastopol) | `XR` "Crimea", continent Europe | Natural Earth's default layer (de facto control) has Crimea as a separate polygon of Russia; the polygons of Russia that Natural Earth's US point-of-view layer (`ne_10m_admin_0_countries_usa`, internationally recognised borders) places in Ukraine are carved out. Neither `RU` nor `UA` contains it. |
| Western Sahara | `EH` "Western Sahara" | The default layer has Morocco covering the whole territory and "W. Sahara" as the Polisario-held strip only. Both `MA` and `EH` take their outlines from the US point-of-view layer instead: `EH` is the whole territory, `MA` stops at 27.66° N. |
| Kosovo | `XK` | Its own feature in the default layer. |
| Northern Cyprus | `XC` | Its own feature in the default layer. |
| Somaliland | `XS` | Its own feature in the default layer. |
| Akrotiri and Dhekelia, Siachen, Bir Tawil, … | `XD`, `XG`, `XT`, … | See the table above. |

Everything else follows Natural Earth's default layer. In it, the Russian-held
parts of mainland Ukraine (Donetsk, Luhansk, Zaporizhzhia and Kherson oblasts)
remain in `UA`. Taiwan is `TW` and Palestine `PS`.
